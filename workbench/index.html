Local LLM

Endpoint path picks the wire format: /v1/chat/completions (OpenAI-compatible: Ollama, LM Studio, LocalAI), /api/chat or /api/generate (Ollama native). For Ollama from file://, start it with OLLAMA_ORIGINS=*.

MCP
local tools only

Without a gateway, tools run locally in this page. With one, remote tools are listed alongside them and routed over SSE.

Penpot (live diagram style)

Streamable HTTP MCP endpoint with an execute_code tool. The hosted Penpot MCP does not allow browser (CORS) requests, so run node penpot-relay.mjs next to this file and keep the default URL — the relay holds your Penpot token. In Penpot, keep the file open with its MCP connection active, then select a board or components (Controller, Controlled Process, Connector Control, Connector Feedback, Group Identity Frame).
