Settings

Active provider

Only the active provider is called. Settings for the others are kept, so you can switch back at any time. The model list beside Send is read from the provider's models endpoint.

Anthropic Claude

Responses stream, so long answers do not time out; the limit is capped at what the chosen model allows. Effort and fallback are only sent to models that accept them.

Calls api.anthropic.com directly from the browser with anthropic-dangerous-direct-browser-access. Your key is visible to anyone using this browser profile — use a restricted key.

Google Gemini

Sent as the x-goog-api-key header (not in the URL).

Local LLM

Endpoint path picks the wire format: a base URL ending in /v1 or the full /v1/chat/completions (OpenAI-compatible: LiteLLM, Ollama, LM Studio, LocalAI), /api/chat or /api/generate (Ollama native). For Ollama from file://, start it with OLLAMA_ORIGINS=*.
