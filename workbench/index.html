Help – Keyboard shortcuts

The underlined letter is the key. Press it alone, without Alt.

  • B Add Below – a block below the selected block
  • S Add Beside – a block beside the selected block
  • Arrows – move the indication to the nearest block
  • Ctrl/⌘+Enter – select the indicated object (same as a click)
  • Enter or F2 – edit the name of the indicated object
  • Shift/Ctrl/⌘+click – add or remove an object of the same kind
  • Delete – delete the selected objects and their links
  • Esc – leave a cell, then clear the selection
  • Ctrl/⌘+Z – undo
  • ? – this help
